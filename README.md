Price Tracking Bot with GUI
Desktop automation tool for tracking and analyzing price data, with graphical interface built in Tkinter.

Key features:

Automated scheduling (runs on defined intervals)
Data visualization with price trend charts (matplotlib)
CSV export for spreadsheet analysis
Automated email notifications
Statistical analysis (min/max/average price tracking)
JSON-based historical data storage

Built using books.toscrape.com, a public sandbox site designed for scraping practice.

"I always check a site's Terms of Service and robots.txt before automating any data collection, and only work with official APIs or explicit client authorization for production projects."
